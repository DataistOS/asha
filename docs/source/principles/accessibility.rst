Accessibility (دسترس پذیری)
===========================

قوانین دسترس پذیری (A11y) برای اطمینان از استفاده تمامی افراد با توانایی های مختلف از سیستم طراحی آشا.

Overview
--------
طراحی فراگیر به این معناست که محصول باید برای همه کاربران، از جمله افرادی با محدودیت های بینایی یا حرکتی، قابل استفاده باشد.

Key Rules (قوانین کلیدی)
------------------------
* **کنتراست رنگی:** نسبت کنتراست متن ها با پس زمینه باید حداقل استانداردهای WCAG (نسخه AA یا AAA) را رعایت کند.
* **ناوبری با کیبورد:** تمام المان های تعاملی باید با کلید Tab قابل دسترسی و استفاده باشند.
* **Focus Rings:** نمایش واضح خطوط دور المان های دارای فوکوس برای کاربران کیبورد.
