Optimizations (بهینه‌سازی ها)
=============================

اصول بهینه سازی عملکرد، رندرینگ روان و کارایی در اجزای رابط کاربری.

Overview
--------
یک رابط کاربری عالی علاوه بر زیبایی باید سریع، سبک و بدون افت فریم (Jank) اجرا شود.

Performance Guidelines (قوانین عملکرد)
---------------------------------------
* **روانی فریم ها (60fps):** انیمیشن ها و اسکرول ها باید بدون لگ و با نرخ فریم پایدار اجرا شوند.
* **مدیریت منابع:** بارگذاری تنبل (Lazy Loading) تصاویر و کامپوننت های سنگین.
* **سبک سازی:** استفاده بهینه از توکن ها و دارایی ها برای کاهش حجم خروجی نهایی.
