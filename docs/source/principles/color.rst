اصول رنگ‌ها (Color Principles)
==============================

در این بخش، فلسفه استفاده از رنگ‌ها در سیستم طراحی «آشا» را بررسی می‌کنیم.
رنگ‌ها در آشا نه فقط برای زیبایی، بلکه برای انتقال مفاهیم (مانند خطا، موفقیت و تاکید) استفاده می‌شوند.

.. note::
   تمامیِ مقادیرِ دقیقِ رنگ‌ها در بخش :doc:`../tokens/colors_auto` قابل مشاهده هستند.
