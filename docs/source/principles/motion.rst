Motion (حرکت و انیمیشن)
=======================

اصول انیمیشن و انتقال های حرکتی در سیستم طراحی آشا (Asha) برای ایجاد تجربه ای طبیعی و پیوسته.

Overview
--------
حرکت در رابط کاربری نباید تزئینی صرف باشد، بلکه باید به کاربر در درک تغییرات، جهت یابی و ارتباط بین المان ها کمک کند.

Duration & Easing (زمان بندی و منحنی ها)
----------------------------------------
* **Fast (سریع - ۱۵۰ میلی ثانیه):** برای تغییرات کوچک و فوری مانند هاور یا تغییر رنگ.
* **Normal (عادی - ۲۵۰ تا ۳۰۰ میلی ثانیه):** برای انیمیشن های استاندارد مانند باز شدن مودال ها یا منوها.
* **Slow (کند - ۴۰۰+ میلی ثانیه):** برای انتقال های بزرگ صفحه یا انیمیشن های ورود پیچیده.
* **Easing:** استفاده از منحنی های طبیعی (مثل ease-out) برای شروع سریع و توقف نرم.
