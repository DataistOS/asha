دکمه‌ها (Buttons)
=================

دکمه‌ها یکی از بنیادی‌ترین عناصر تعاملی در سیستم طراحی آشا هستند که برای انجام کنش‌ها (Actions) در رابط کاربری استفاده می‌شوند.

فلسفه طراحی
-----------
دکمه‌های آشا باید به‌گونه‌ای طراحی شوند که برای کاربر کاملاً متمایز و قابل‌تشخیص باشند. ما با استفاده از سیستم توکن‌های معنایی (Semantic Tokens)، اطمینان حاصل می‌کنیم که تمامی دکمه‌ها در پلتفرم‌های مختلف (وب و موبایل) رفتاری یکسان داشته باشند.

استفاده از توکن‌ها
------------------
برای حفظ یکپارچگی، تمامی دکمه‌ها از توکن‌های سیستمی استفاده می‌کنند. در حال حاضر، رنگ پس‌زمینه دکمه‌ها مستقیماً به توکن زیر متصل است:

* **پس‌زمینه:** ``{semantic.color.primary}``

هرگونه تغییر در رنگ اصلی سیستم (Primary Color) که در بخش :doc:`../principles/color` تعریف شده است، به‌طور خودکار در دکمه‌ها نیز اعمال خواهد شد.

راهنمای پیاده‌سازی
------------------
هنگام استفاده از کامپوننت دکمه، حتماً موارد زیر را رعایت کنید:

1. **خوانایی:** متن داخل دکمه باید با توجه به رنگ پس‌زمینه، کنتراست کافی داشته باشد.
2. **سلسله‌مراتب:** از دکمه‌های Primary برای کنش‌های اصلی و از سایر حالات برای کنش‌های ثانویه استفاده کنید.

.. note::
   برای مشاهده مقادیر دقیق رنگی اختصاص داده شده به ``semantic.color.primary``، به فایل :doc:`../tokens/colors_auto` مراجعه کنید.
