# ارغوانی میوه انجیر (Fig Fruit Mauve)

در این بخش، تحلیل دقیق ارغوانی میوه انجیر و روابط هارمونیک آن در سیستم طراحی «آشا» بررسی شده است.

## اطلاعات فنی رنگ ارغوانی میوه انجیر (#A98691)

رنگ ارغوانی میوه انجیر در فهرست طراحی رال (RAL Design) با شماره 360 60 15 گنجانده شده است. کد رنگ هگز آن #A98691 و معادل RGB آن (169, 134, 145) است. این رنگ یک رنگ وب (Web Color) نیست؛ بنابراین نمی‌توان آن را با نام در HTML و CSS فراخوانی کرد، اما می‌توانید از کد هگز، RGB یا HSL برای اعمال آن در صفحات وب استفاده کنید.

دقت کنید که مقادیر CMYK و رنگ پانتون برای این رنگ، از طریق فرمول‌های استاندارد و بر اساس کد هگز محاسبه شده‌اند و صرفاً مقادیر تقریبی هستند. سیستم رال (RAL) یک سیستم تطبیق رنگ محبوب است که در کشورهای اروپایی از جمله آلمان، فرانسه، ایتالیا و بریتانیا استفاده می‌شود.

### مشخصات فنی
* **کد هگز:** #A98691
* **مقادیر RGB:** (169, 134, 145)
* **مقادیر CMYK:** (0%, 21%, 14%, 34%)
* **مقادیر HSV/HSB:** (341°, 21%, 66%)
* **نزدیک‌ترین رنگ ایمن وب:** #999999
* **شماره پانتون:** 5005 C
* **نزدیک‌ترین کد RAL:** 4009 [Pastel violet]
