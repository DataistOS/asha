# بنفش تیره انجیر (Dark Fig Violet)

در این بخش، تحلیل دقیق بنفش تیره انجیر و روابط هارمونیک آن در سیستم طراحی «آشا» بررسی شده است.

## اطلاعات فنی رنگ بنفش تیره انجیر (#573B4C)

رنگ بنفش تیره انجیر در فهرست طراحی رال (RAL Design) با شماره 340 30 15 گنجانده شده است. کد رنگ هگز آن #573B4C و معادل RGB آن (87, 59, 76) است. این رنگ یک رنگ وب (Web Color) نیست؛ بنابراین نمی‌توان آن را با نام در HTML و CSS فراخوانی کرد، اما می‌توانید از کد هگز، RGB یا HSL برای اعمال آن در صفحات وب استفاده کنید.

دقت کنید که مقادیر CMYK و رنگ پانتون برای این رنگ، از طریق فرمول‌های استاندارد و بر اساس کد هگز محاسبه شده‌اند و صرفاً مقادیر تقریبی هستند. سیستم رال (RAL) یک سیستم تطبیق رنگ محبوب است که در کشورهای اروپایی از جمله آلمان، فرانسه، ایتالیا و بریتانیا استفاده می‌شود.

### مشخصات فنی رنگ بنفش تیره انجیر
* **کد هگز:** #573B4C
* **مقادیر RGB:** (87, 59, 76)
* **مقادیر CMYK:** (0%, 32%, 13%, 66%)
* **مقادیر HSV/HSB:** (324°, 32%, 34%)
* **نزدیک‌ترین رنگ ایمن وب:** #663333
* **شماره پانتون:** 7659 C
* **نزدیک‌ترین کد RAL:** 7022 [Umbra grey]
