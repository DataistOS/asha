# زرد خردلی انجیر (Fig Mustard Yellow)

در این بخش، تحلیل دقیق زرد خردلی انجیر و روابط هارمونیک آن در سیستم طراحی «آشا» بررسی شده است.

## اطلاعات فنی رنگ زرد خردلی انجیر (#BB8610)

رنگ زرد خردلی انجیر در فهرست طراحی رال (RAL Design) با شماره 080 60 60 گنجانده شده است. کد رنگ هگز آن #BB8610 و معادل RGB آن (187, 134, 16) است. شما می‌توانید از این مقادیر به همراه مقادیر HSL در کدهای HTML و CSS برای نمایش رنگ در صفحات وب استفاده کنید.

دقت کنید که مقادیر CMYK و رنگ پانتون برای این رنگ، از طریق فرمول‌های استاندارد و بر اساس کد هگز محاسبه شده‌اند و صرفاً مقادیر تقریبی هستند. سیستم رال (RAL) یک سیستم تطبیق رنگ محبوب است که در کشورهای اروپایی از جمله آلمان، فرانسه، ایتالیا و بریتانیا استفاده می‌شود و کاتالوگ رال دیزاین (RAL Design) اختصاصاً برای رنگ‌های فضای داخلی کاربرد دارد.

### مشخصات فنی
* **کد هگز:** #BB8610
* **مقادیر RGB:** (187, 134, 16)
* **مقادیر CMYK:** (0%, 28%, 91%, 27%)
* **مقادیر HSV/HSB:** (41°, 91%, 73%)
* **نزدیک‌ترین رنگ ایمن وب:** #CC9900
* **شماره پانتون:** 1245 C
* **نزدیک‌ترین کد RAL:** 1005 [Honey yellow]
