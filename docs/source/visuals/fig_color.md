# رنگ انجیر (Fig Color)

در این بخش، تحلیل دقیق رنگ انجیر و روابط هارمونیک آن در سیستم طراحی «آشا» بررسی شده است.

## اطلاعات فنی رنگ انجیر (#532E3B)

رنگ انجیر در فهرست «نساجی کتان توسعه یافته» پانتون (Pantone TCX) با شماره 19-1718 TCX گنجانده شده است. کد رنگ هگز آن #532E3B و معادل RGB آن (83, 46, 59) است. این رنگ یک رنگ وب (Web Color) نیست؛ بنابراین نمی‌توان آن را با نام در HTML و CSS فراخوانی کرد، اما می‌توانید از کد هگز، RGB یا HSL برای اعمال آن در صفحات وب استفاده کنید.

دقت کنید که پانتون مقادیر CMYK را برای این رنگ ارائه نکرده است. اعداد RAL و CMYK که در اینجا مشاهده می‌کنید، از طریق فرمول‌های استاندارد و بر اساس کد هگز محاسبه شده‌اند و صرفاً مقادیر تقریبی هستند.

### مشخصات فنی رنگ انجیر
* **کد هگز:** #532E3B
* **مقادیر RGB:** (83, 46, 59)
* **مقادیر CMYK:** (0%, 45%, 29%, 68%)
* **مقادیر HSV/HSB:** (339°, 45%, 33%)
* **نزدیک‌ترین رنگ ایمن وب:** #663333
* **شماره پانتون:** 19-1718 TCX
* **نزدیک‌ترین کد RAL:** 4007 [Purple violet]
