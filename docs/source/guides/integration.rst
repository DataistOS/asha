راهنمای یکپارچه‌سازی
=================

این راهنما توضیح می‌دهد که چگونه توکن‌های طراحی تولیدشده را در پروژه‌های خود مصرف کنید. با استفاده از «منبع واحد حقیقت» (SSOT) ما، ثبات را در تمامی پلتفرم‌ها تضمین می‌کنید.

نمای کلی
--------
توکن‌ها به‌صورت خودکار از فایل‌های طراحی اصلی ما تولید شده و در قالب‌های متعددی توزیع می‌شوند:

* **JSON:** داده‌های خام برای ابزارهای سفارشی.
* **CSS/SCSS:** برای برنامه‌های تحت وب.
* **Dart:** برای برنامه‌های موبایل فلاتر.

یکپارچه‌سازی وب (CSS)
---------------------
شما می‌توانید به متغیرهای CSS تولیدشده مستقیماً از پوشه ساخت (build) دسترسی داشته باشید. کافی است فایل توکن‌ها را در پروژه خود فراخوانی کنید:

.. code-block:: css

   @import '~asha-tokens/build/css/tokens.css';

   /* نمونه استفاده */
   .my-element {
       color: var(--color-brand-primary);
       font-size: var(--typography-body-base-size);
   }

یکپارچه‌سازی فلاتر (Dart)
--------------------------
ما یک کتابخانه Dart با ایمنی نوع (Type-safe) ارائه می‌دهیم. پس از نصب بسته، می‌توانید از طریق کلاس ``Asha`` به تمامی توکن‌ها دسترسی داشته باشید:

.. code-block:: dart

   import 'package:asha_flutter_tokens/tokens.dart';

   // نمونه استفاده
   Container(
     color: Asha.semantic_tokens.brandPrimary,
     child: Text(
       "Hello Asha",
       style: Asha.typography_tokens.bodyBase,
     ),
   )

به‌روزرسانی توکن‌ها
---------------
هر زمان که توکن‌های طراحی در فایل‌های منبع به‌روزرسانی شدند، برای انتشار تغییرات مراحل زیر را دنبال کنید:

1. اجرای اسکریپت ساخت: ``npx style-dictionary build``
2. اعتبارسنجی توکن‌ها: ``python3 scripts/validate_tokens.py``
3. اجرای تست‌ها: ``./tests/test-tokens.sh``
4. ثبت (Commit) تغییرات برای فعال‌سازی خط لوله (Pipeline).
