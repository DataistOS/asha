# Asha Assets Repository

این دایرکتوری، منبعِ واحدِ حقیقت (SSOT) برای تمامی دارایی‌هایِ بصری و گرافیکیِ اکوسیستمِ **Dataist** است.

## ساختار دایرکتوری‌ها

- **`brand/`**: دارایی‌هایِ هویتی و سازمانی (غیرقابل تغییر توسط تیم توسعه).
- **`components/`**: دارایی‌هایِ مربوط به UI (آیکون‌ها، ایلاستریشن‌ها و مواردِ کامپوننت‌محور).
- **`typography/`**: فایل‌هایِ فونت و استایل‌هایِ متنی.
- **`documentation/`**: تصاویرِ اختصاصی برایِ مستنداتِ فنی (دیاگرام‌ها، راهنماها).
- **`exports/`**: خروجی‌هایِ بهینه‌شده برایِ استفاده در پلتفرم‌هایِ مختلف (فلاتر، وب و غیره).

---

## دستورالعملِ مشارکت
1. **قانونِ طلایی**: فایل‌هایِ اصلی (Master) را تغییر ندهید؛ همیشه خروجی‌هایِ بهینه‌شده را در پوشه‌یِ `exports/` تولید کنید.
2. **فرمت‌ها**: ترجیحاً برایِ آیکون‌ها از `SVG` و برایِ تصاویرِ غیرِ وکتور از `WebP` استفاده کنید.
3. **نام‌گذاری**: از قراردادِ `kebab-case` استفاده کنید (مثال: `button-icon-primary.svg`).

```text
assets/
├── brand/               # هویت اصلی و سازمانی
│   ├── logos/           # لوگوهای اصلی
│   ├── logotypes/       # تایپوگرافی لوگوها
│   └── colors/          # پالت‌های مرجع
├── components/          # دارایی‌های UI
│   ├── icons/           # آیکون‌های سیستم
│   ├── illustrations/   # تصویرسازی‌ها
│   └── placeholders/    # تصاویر پیش‌فرض
├── typography/          # فونت‌های اکوسیستم
│   └── fonts/           # فایل‌های .ttf / .otf
├── documentation/       # دارایی‌های مخصوصِ مستندات
│   ├── diagrams/        # دیاگرام‌های معماری
│   └── visuals/         # تصاویر نمایشی مستندات
└── exports/             # خروجی‌های بهینه‌شده
    ├── flutter/         # مخصوص پکیج فلاتر
    └── web/             # مخصوص وب
```
